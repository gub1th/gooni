Gooni Browser Sensor

Records the active tab's URL and how long it held focus. Idle time and backgrounded windows count as nothing.

Exchanged once at POST /auth for the bearer token. The password itself is not stored.

Privacy: scrubbed query parameters

Full URLs are captured for every host — a hostname alone can't tell you what you were distracted by, and the LeetCode problem you're working on lives in the path. The exception is credentials: any query parameter whose name contains one of these segments has its value replaced with REDACTED before the URL is ever written to disk, so OAuth callbacks and password-reset links can't land in the log. The URL fragment (#…) is always dropped. Everything else survives — a YouTube video id in ?v= is exactly the identity the log needs.

The parameter name is lowercased and split on _, -, camelCase and digit boundaries; if any piece is on this list, the value is redacted. So token covers access_token, X-Amz-Security-Token and accessToken, while sig does not touch design and auth does not touch author.

Two fixed checks run alongside this list and cannot be edited away: the bare OAuth names code, key and state (whole name only, so zip_code survives), and the run-together names jsessionid, phpsessid, sessionid, csrftoken, accesstoken, apikey, xapikey, xfunctionskey, subscriptionkey — compared after underscores and hyphens are removed, so those last four also cover api_key, x-api-key, x-functions-key and subscription-key.
